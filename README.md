# Shikho for RYZE customers: prototype

A clickable prototype of how RYZE customers find, buy and use Shikho courses.

Open `index.html` in a browser. Pick a flow, then tap the phone or use Next.

Flows:

1. First purchase
2. Coming back with an active pack
3. Buying again (days add up)
4. Pack ended

RYZE screens follow the RYZE app. Prices are samples. A concept made by Shikho for discussion.
